# Airlines Data Pipeline

## Project Overview

This project develops a simple airline data pipeline using Python.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Tkinter
- SQLite
- GitHub

## Data Pipeline

CSV Files  
↓  
Data Cleaning  
↓  
Data Validation  
↓  
Table Joining  
↓  
Date and Time Processing  
↓  
Flight Duration Calculation  
↓  
KPI Calculation  
↓  
SQLite Database  
↓  
Dashboard

The dashboard shows:

- Total Bookings
- Total Passengers
- Confirmed Bookings
- Total Revenue
- Bookings by Airline
- Booking Status
- Revenue by Airline
- Payment Methods

## Privacy

Original airline datasets and passenger personal information are not included in this public repository.
